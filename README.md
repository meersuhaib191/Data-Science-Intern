# Data Science Internship – iQuasar Software Solutions

## Overview
This repository contains all the work completed during my **Data Science Internship** at **iQuasar Software Solutions** from **January 2026 to April 2026**.  
The internship focused on practical implementation of data science concepts including data preprocessing, exploratory data analysis, feature engineering, hypothesis testing, machine learning model building, and dashboard visualization.

---

## Objectives
The main objectives of this internship were:

- Understanding the data science workflow
- Learning data cleaning and preprocessing techniques
- Performing Exploratory Data Analysis (EDA)
- Applying statistical analysis and hypothesis testing
- Building machine learning models
- Evaluating model performance
- Creating interactive dashboards using Power BI
